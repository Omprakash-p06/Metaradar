## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend -> Google Gemini API | Prompts cross to third party; privacy gate plus PII scrubber bound the exposure |
| env -> provider | GEMINI_API_KEY via server env only, never client bundle |
| provider -> business logic | Untrusted model output; schema validation before use |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-08 | Information Disclosure | Gemini prompts on free tier | high | mitigate | Mandatory validate_privacy_gate PUBLIC/SYNTHETIC only plus PII scrubber; tradeoff documented in deploy docs |
| T-15-09 | Information Disclosure | GEMINI_API_KEY | high | mitigate | Server-side env only; empty default; never logged; never shipped in any client |
| T-15-10 | Tampering | model output into app logic | medium | mitigate | Structured-output schema validation; malformed output raises GeminiUnavailableError to degraded |
| T-15-11 | Elevation of Privilege | cloud model action execution | high | mitigate | No GENERATE_ACTIONS capability; rules, validation, permissions, and execution stay deterministic in app code |
| T-15-12 | Denial of Service | Gemini 429 and quota exhaustion | medium | mitigate | Bounded retries with backoff plus jitter, then controlled degraded payload with fallback_reason; core flows never break |
